# Sistema de ventas y fundamentos de Java

Proyecto académico desarrollado en **Java** con el objetivo de aplicar distintos conceptos fundamentales de programación mediante un programa de consola con varias funcionalidades.

## 📌 Descripción

El programa cuenta con un menú principal que permite acceder a tres módulos:

1. **String, Math, printf y Regex**
2. **Registro de ventas**
3. **Matemática avanzada**

Cada módulo permite practicar diferentes conceptos de Java, validación de datos y resolución de problemas.

## 🚀 Funcionalidades

### 🔤 String, Math, printf y Regex
- Manipulación de cadenas de texto.
- Uso de métodos como `trim()`, `length()`, `substring()`, `contains()` y `replace()`.
- Operaciones utilizando la clase `Math`.
- Formateo de resultados mediante `printf`.
- Validación de correo, cédula y teléfono mediante expresiones regulares (Regex).

### 🛒 Registro de ventas
- Registro de productos y precios.
- Validación de fecha y hora.
- Aplicación de descuentos mediante diferentes condiciones.
- Cálculo del valor ahorrado y valor final a pagar.
- Generación de un resumen de las ventas realizadas.

### 📐 Matemática
Incluye diferentes operaciones matemáticas:
- Derivadas básicas.
- Ecuaciones cuadráticas.
- Sucesiones aritméticas.
- Tablas de suma, multiplicación y potencia.

## 🧠 Conceptos de Java utilizados

- Variables y tipos de datos
- Métodos
- `Scanner`
- `if / else`
- `switch`
- Ciclos `while`, `do-while` y `for`
- Arrays
- `String`
- Clase `Math`
- Expresiones regulares (Regex)
- `try / catch`
- `printf`
- Validación de datos

## 🛠️ Tecnología

- **Lenguaje:** Java
- **Tipo de aplicación:** Programa de consola
- **IDE utilizado:** NetBeans

## ▶️ Ejecución

El programa inicia mostrando el siguiente menú:

1. String, Math, printf, Regex
2. Registro de ventas
3. Matemática avanzada
4. Salir

El usuario selecciona una opción y el programa ejecuta el módulo correspondiente.
